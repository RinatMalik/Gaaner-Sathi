# Gaaner Sathi (গানের সাথী): handover pack

Unzip this into the root of the new project, then paste `KICKOFF.md` into Claude Code.

    KICKOFF.md                      the kickoff prompt (paste this)
    docs/NOTATION.md                notation spec: beats, notes, octaves, editor operations, checker
    docs/ENGINE.md                  audio and timing engine: scheduler, taals, rhythm, harmonium, tanpura
    docs/DATA.md                    song model, file format, settings, storage
    reference/gaaner-sathi.html    the working prototype (open it in a browser; it runs offline)
    reference/exercises.json        the 12 built-in exercises
    reference/tests/                test suites for the prototype (run-all.sh)

Bring your own songs across by opening the prototype on claude.ai, pressing "Back up all my songs",
and importing that file into the new app once Phase 1 is done.
